# 🚀 PM Hub - Frontend

Frontend aplikacija za Trello klon projekat, bazirana na React-u, Vite-u i Tailwind CSS-u.

---

## 🛠️ Tehnologije i biblioteke

| Biblioteka                     | Svrha                                                            |
|--------------------------------|------------------------------------------------------------------|
| ⚛️ **React 18**               | Glavna biblioteka za izradu korisničkog interfejsa (UI)           |
| ⚡ **Vite**                   | Brzi development server i build alat                              |
| 🎨 **Tailwind CSS**           | Utility-first CSS framework za brzo stilizovanje                  |
| 📡 **Axios**                  | HTTP klijent za komunikaciju sa backend API-jem                   |
| 🌐 **React Router DOM**       | Upravljanje rutama i navigacijom u React aplikaciji               |
| 🧪 **React Query** (opciono)  | Efikasno keširanje i upravljanje asinhronim podacima (API pozivi) |
| 🧩 **React DnD** (opciono)    | Drag and drop funkcionalnost (pomera taskove i kolone)            |
| 🛠️ **ESLint + Prettier**      | Alati za statičku analizu koda i automatsko formatiranje          |
| 💡 **TypeScript**             | Statički tipizirani JavaScript za bolje greške i održavanje koda  |

---

## 📋 Preduslovi

- 🟢 Node.js (preporučena verzija: >= 20.19.0)
- 📦 npm (dolazi sa Node.js)
